# 🏃 Subway Surfers Lite 3D (Cyber Rush)

An ultra-lightweight, high-performance 3D endless runner web game inspired by *Subway Surfers*. Built natively with **WebGL (Three.js), HTML5, CSS Glassmorphism, and the Web Audio API**.

---

## ⚡ Key Highlights

- 🚀 **Zero Heavy 3D Downloads**: Procedural 3D meshes for tracks, subway trains, caution hurdles, ramps, gold coins, and power-up boxes. Loads in less than 1 second!
- 🏃 **Full Parkour & Runner Movement**:
  - 3 Snappy lanes with bank-lean tilt physics.
  - Jump over hurdles & jump onto moving train roofs.
  - Slide/Roll under high warning beams + instant mid-air dive down.
  - Train-surfing with wedge ramps and moving oncoming express trains!
- 🧲 **Dynamic Power-Ups**:
  - 🧲 **Coin Magnet**: Electromagnetically pulls coins toward the player in a 12m radius with glowing arcs.
  - 🚀 **Jetpack**: Skyrocket above tracks with rocket flame effects, flying safely above ground hazards.
  - ⚡ **2X Multiplier**: Double all score and coin earnings.
  - 🛹 **Hoverboards**: Activated via Space / Double-Tap; grants a single-collision protective shield with neon engine trails.
- 🎵 **Synthesized Retro-Arcade Audio**:
  - 100% procedurally synthesized sound effects and upbeat synth BGM using Web Audio API oscillators (no external mp3/wav files required).
- 🛒 **Runner Locker & Upgrades**:
  - Unlock new character skins (*Speedster Dash*, *Cyber Neon*, *Golden Champion*) and hoverboard variants (*Cyber Wave*, *Inferno Flame*, *Plasma Surge*) using collected coins.
- 📱 **Cross-Platform Responsive Controls**:
  - Desktop keyboard (WASD / Arrow keys / Space / P).
  - Mobile & Tablet touch swipe gestures + double-tap.

## 🎮 Controls

| Action | Desktop Keyboard | Mobile / Tablet |
| :--- | :--- | :--- |
| **Move Left / Right** | `←` / `→` or `A` / `D` | Swipe Left / Swipe Right |
| **Jump** | `↑` / `W` | Swipe Up |
| **Slide / Fast Fall** | `↓` / `S` | Swipe Down |
| **Summon Hoverboard** | `Space` or `B` | Double Tap Screen |
| **Pause Game** | `P` or `Esc` | Pause Button `⏸️` |
| **Mute / Unmute** | Sound Button `🔊` | Sound Button `🔊` |

## 🚀 How to Run Locally

You can open `index.html` directly in any modern browser or run a simple local web server:

```bash
# Using Python
python -m http.server 8000

# Or using Node
npx serve .
```

Then visit: `http://localhost:8000`
